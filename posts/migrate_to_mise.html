dotfiles管理をmiseに移行した

published: 2026-10-25

私物Macと仕事Macのdotfilesとアプリ管理をmise bootstrapで管理しやすくした - $shibayu36->blog; を参考に、 今までGNU Stowでやってたdotfiles管理をmise bootstrapに移行した。

元々、以下のようなStow用に（Stowにおける）パッケージごとにディレクトリ切ってた。

  • agents
  • config
  • etc
  • git
  • macos
  • shell
  • vim

miseでもこれを踏襲して、それぞれをdotfile_groups にした。

こういうの。

[dotfile_groups.shell]
root = "shell"
target = "~"
mode = "symlink-each"

[dotfile_groups.vim]
root = "vim"
target = "~"
(略)

なので、移行内容としてはmiseの設定ファイルを置いたり、移行用のスクリプトを用意するだけで済んだ。

どちらもLLM任せ。いやー、いい時代ですね。

ツールのバージョンとかもasdf使ってたけど、miseに移行して良いかも。
